Build BrickLink bulk-upload XML either by typing rows directly into the grid, or by pasting XML from your sheet. Either way the output is cleaned into the format BrickLink's Bulk Upload accepts, ready to drop into "Verify Items" without the usual format errors.

1 Fill in the rows

One part per row. Part ID, Color, Qty, and Price are required; Remarks and Description are optional. Press Tab to move across, Enter to drop a row. Everything auto-saves to this browser.

Required fields & valid values (click to expand)

Required per item: ITEMTYPE, ITEMID, QTY, PRICE, CONDITION. For parts and minifigs you also need COLOR (color ID). Tip: your sheet probably says "MINQTY" or "Quantity" — the converter maps those to QTY automatically.

ITEMTYPE: P = Part, M = Minifig, S = Set, G = Gear, B = Book, C = Catalog, I = Instruction, O = Original Box

CONDITION: N = New, U = Used

Optional: DESCRIPTION, REMARKS, MYCOST, BULK, SALE, STOCKROOM, RETAIN, SUBCONDITION, TIERQTY1..3, TIERPRICE1..3, BUYERUSERNAME, NOTIFY
