BrickLink Guide #2: A Bin Naming Scheme That Scales

Piece Pavilion · November 4, 2026 · 4 min read

A few times a week we post a short guide for other BrickLink sellers — the small, specific things that have actually helped us move inventory. New guides land every Monday, Wednesday and Friday. If one of them helps you, that is a win.

In Guide #1 we said every lot needs a bin location in Remarks. This guide is the how: a naming scheme you can set up in one afternoon and still be using when the store has ten times the inventory.

1. Name the place, not the part

A bin code should describe where a drawer or box physically sits, never what is in it. The moment a code means “black plates” you are stuck: black plates outgrow the drawer, a new color arrives, and every code tied to the contents has to change. A code tied to a location never has to change. Contents move; the shelf stays where it is.

2. Use three parts: aisle, shelf, slot

Keep the code short enough to read at a glance from a pick sheet. A pattern that works is a letter for the shelving unit, a number for the shelf counted from the bottom, and a letter for the position left to right. So B3-C is unit B, third shelf up, third box across. If you only have one shelving unit, drop the first part and use shelf and slot. If you have a whole room, add a leading letter for the zone. Add parts only when you run out of room, not before.

  • Letters for things you count left to right, numbers for things you count bottom to top. Mixing them keeps codes from blurring together when you read them fast.
  • Skip characters that look alike. Do not use both O and 0, or both I and 1.
  • Write the code on the container itself, on the front where you can see it without pulling the box out.

3. Label the shelf first, then fill it

Do the labeling before you move any inventory. Print or write the codes, stick them on the shelves and boxes, and only then start putting lots away. If you label after the fact, you will label what you remember rather than what is there, and those are the lots that turn up with wrong bins months later.

4. Put the code in Remarks, and only the code

BrickLink prints Remarks on the pick sheet, so Remarks is the place for the bin and nothing else. Resist the urge to add notes like “check count” or “sealed bag” in the same field. A pick sheet line with a bare code reads instantly. A line with a sentence slows you down on every single order. If you need a note on a lot, keep it somewhere that does not print in your picking path.

When one lot is split across two containers, enter both codes separated by a slash, like B3-C/B3-D, so the picker knows to look in both before deciding it is out of stock.

5. Sort the pick sheet, then walk it once

A bin scheme pays off when the pick sheet is sorted by Remarks, so the order of items on paper matches the order of your walk. Sort by Remarks, start at one end of the room, and finish at the other without doubling back. If you find yourself crossing the room twice for one order, the scheme is telling you a popular lot lives too far from the packing table. Move the lot, and change its code.

6. Audit one shelf a week

Bins drift. Lots get restocked into the wrong box, and a code goes stale. Pick one shelf a week, check that every lot with that prefix is actually there, and fix the ones that are not. A single shelf takes a few minutes. Doing it weekly keeps the problem small, and it is far cheaper than discovering a hundred wrong bins at once.

The takeaway

Name locations, keep the code short, label before you fill, and put nothing but the code in Remarks. Do those four things and picking turns from searching into walking.
